# P1 离线画布实现

本阶段将既有设计转换为 React / TypeScript / Vite 应用。它消费明确标记的离线 Fixture，不连接模型、账户、工具执行器或 Echidna 核心。

## 代码职责

| 位置 | 当前职责 |
| --- | --- |
| `web/model/schema.ts` | 离线事件、输入快照、画布文档与保存结构的版本化边界校验 |
| `web/model/projection.ts` | 从完整事件或选定前缀生成会话、轮次、调用与交接投影；无 I/O |
| `web/model/fixtures.ts` | 确定性事件源；待接收片段与已发生记录分开 |
| `web/model/workspace.ts` | 接收下一事件、创建角色、采用新路线、草稿历史与复制视图 |
| `web/model/storage.ts` | 读取浏览器记录；错误显式返回并保留原始字节 |
| `web/canvas/` | 坐标、缩放锚点、形状、Pointer Events、框选、组拖动和连线 |
| `web/records/` | 局部记录、决策/事后评估、来源关系与完整参数回传 |
| `web/agents/`、`web/dialogue/` | 图集动作、角色配置、固定来源的对话建议和路线纠正 |
| `web/files/`、`web/settings/` | 版本化演示文件、只读建议比较、九色主题与底纹 |
| `web/app/` | 应用装配、菜单、详情、回放计时器与浏览器保存 |

Vite 的本地开发服务器只提供前端资源。本阶段没有新增 AgentLoop、编排服务、数据库或运行时网络 API。

## 事实、演示计划与视图

`Workspace.events` 是离线演示中已经接收的事实；未来片段只位于 `replays.steps`，不参与当前投影。`project(events, through)` 是实时与历史画面共用的唯一投影入口。子角色、回传与采纳只有在对应前缀内出现时才能显示。

画布保存根会话引用、角色位置、视角、草稿、草稿撤销栈、历史前缀和待采用建议。草稿编辑不生成执行事件，撤销与橡皮不会删除会话记录。复制画布只复制这些视图数据，共用原事件来源与回放计划。

自动布局由稳定的会话、路线和轮次顺序确定。新增记录不重排已生成的节点；拖动根角色改变对应画面位置。依据回传使用明确引用连线，顺序线不自动表示因果。

## 停止、纠正与配置

- 暂停回放只停止浏览器计时器。
- 暂停后续采样阻止下一次 `round.started`，已有工具结果仍能接收。
- 取消请求与返回结果独立。请求取消后仍收到结果时，保留真实 Fixture 回传和回执引用。
- 演示断线阻止继续接收，恢复后从原游标继续；不会重新发出已有工具调用。
- 对话保存 `sessionId / routeId / roundId / eventSeq`；后台新增事件不改变该来源。采用建议才追加新路线，旧路线后续采样暂停，原输入与位置保留。
- 运行详情保留旧路线接收入口；父会话暂停采样不暂停已经创建的独立子会话。子输入通过不可变的路线来源引用父任务的确切委派前缀。
- 角色、模型示例和工作偏好独立。配置更新只用于后续轮次的输入快照；任务改动形成新路线。账户登录不在本阶段模拟为成功。

## 浏览器保存

使用一个带版本的 `localStorage` 文档，包含演示事件、演示游标与画布视图。每次变更后合并保存；`pagehide` 时保存尚未落下的最新改动，以免紧接着刷新丢失最后一次编辑。只有写入成功后界面才显示已保存。

解析失败不会自动重置或覆盖原记录，用户可以下载原始数据或明确重置离线演示。写入失败会显示原因。本阶段的浏览器保存不等于真实 Session 持久化、进程恢复或跨设备同步，也不包含 Provider 凭据。

## 验证入口

`npm test` 覆盖流式参数与回传顺序、历史前缀、独立子输入、配置快照、路线来源、暂停/取消/重连、复制引用、草稿恢复、缩放锚点与保存边界。

`npm run test:e2e` 使用 Playwright 启动独立的测试 Chromium，检查三个场景、精确分叉、历史冻结、角色交接、手工编辑、临时连接、刷新恢复、文件版本、主题、减少动态效果和 320/736/1024px 界面。测试浏览器只用于开发验证；用户运行 Web 应用不需要安装它。首次运行测试使用 `npx playwright install chromium`。

具体执行结果与剩余限制见 STATUS。P2 才验证正式事件/控制接口与 RuntimeBridge；当前离线 Schema 不是对外冻结 API。
