## P1 的三份固定主场景

1. **工具反馈改变判断**：读到 `snapshot@v2` 后保留两个解释；并行核对格式与兼容处理；下一轮选择最小复现与独立复核。
2. **用户中途纠正方向**：在指定事件前缀加入“先核对真实环境，不修改文件”；采用后生成新路线，原路线保持可回看。
3. **委派、复核与采纳**：父会话只传 `snapshot@v2` 和两份工具回传；子会话独立复核；父会话采纳定位事实，并保留真实影响未验证的限制。

## 故障注入清单

- 参数尚未完整；参数校验拒绝；工具真实失败；回执发布失败。
- 创建被受理后进程断开；重复 command_id；同来源重复事件；事件缺口/乱序。
- 取消请求后收到真实完成；断线期间工具仍完成；恢复前副作用未知。
- 第三个子 Agent 超额；两个并发请求争用最后额度；子会话失联。
- 修改建议的基础版本过期；读取文件后路径内容改变。
- 历史快照打开时产生子 Agent、回传和采纳；复制后新启动任务。

## 记录要求

验证记录区分已实现事实、Fixture 结果、真实执行结果和未验证项。不得以退出码成功代替最终结果验收，也不得把观察、采纳或图形连线写成已验证研究结论。
