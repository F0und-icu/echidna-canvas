# 长任务与片段分支验收

日期：2026-10-17。用户要求优化终端命令展示，运行接近参考设计的真实长任务，并从中间片段对话开出只继承此前上下文的独立分支。

## 实现边界

完整回合仍使用 Codex 原生 thread/fork(lastTurnId)。目标版本 0.149.0 不提供任意 item 截断；片段级分支使用正式 thread/inject_items 注入公开记录快照。原用户输入保持原文，当前回合的公开回复、标注、命令参数与已收到的结果组成带来源的 assistant 快照，不伪造原生工具调用，不加入隐藏 reasoning。此前完整回合和当前局部快照分别处理。

`resolveBranchPoint` 统一校验来源 eventId，重建确切事件前缀；快照与继承的对话视图使用同一前缀。支持标注发布、工具返回和工具失败节点；未返回的工具没有可用分支边界。创建只复制上下文，打开新对话面板，由用户的新消息开始新回合。来源之后的聊天、标注和回传不会进入分支。文件与外部状态共享，不因上下文分支回滚。

## 尚存限制

片段快照不等同原生完整内部上下文。模型重新读取共享目录可能获得聊天边界以外的文件现状，这不是继承了未来聊天。第一次迁移回合仍保留 unknown；只读核对没有把缺失通知补写成原回合成功。后端跨重启 Resume 和 AI 委派仍不在本轮实现范围。

全景为了容纳真实长任务和对照回合而缩小，细小命令与长文应通过放大、节点详情和完整回复阅读；不声称与参考图逐像素一致或窄屏全景可读性已通过。
